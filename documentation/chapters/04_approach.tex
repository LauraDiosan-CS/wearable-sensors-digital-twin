\chapter{Investigated approach}
\label{chapter:proposedApproach}

This chapter describes the first version of the pipeline and its first results (Seminar~4). All experiments use public PhysioNet data \cite{goldberger2000physiobank}. Models are always trained on one group of patients and tested on a different group, so every result describes patients the models have never seen.
